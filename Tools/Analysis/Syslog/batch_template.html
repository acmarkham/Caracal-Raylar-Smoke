Nodes and individual reports

Position and radio links

Shared offline position map: median valid GPS fixes, east/north in projected metres relative to the first node. Positions retain the individual report’s 50 km coordinate obfuscation; separations above 25 km are ambiguous. No geographic basemap or absolute coordinates are exported. Arrows point from sender to receiver; opposing directions are offset. Nodes without fixes are omitted from the map.

Counts are observed receptions across all boots in this batch, not packet delivery rates. Missing links do not prove a failed path. RSSI/SNR averages use only available metadata; missing SNR stays unavailable. External sender IDs can appear in the table without a position.

Battery discharge

UTC aligns devices and boots. Runs without a UTC anchor appear only in the summary table. Charging and load changes can affect discharge; endpoint SOC change is not a battery lifetime estimate.

Tilt and magnetic heading

Pitch = atan2(−X, √(Y²+Z²)); roll = atan2(Y,Z), using board accelerometer axes. Magnetic XY bearing = atan2(Y,X), wrapped to 0–360°. Heading is uncalibrated, without tilt compensation or declination correction. Board mounting and antenna alignment are unknown; these readings suggest board orientation, not a verified antenna direction. Summary values are the latest valid readings; plotted values show movement during deployment.
